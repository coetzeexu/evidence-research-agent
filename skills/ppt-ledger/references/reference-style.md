# 账页式数据复盘规范

从指定模板的 `spec_lock.md` 与封面、scorecard SVG 提取：
1280×720 画布，左右 64px 边距，白纸、发丝线、严格分栏和基线。
封面主题在左上，关键数字排列在下方；内容页顶部为标题/口径，中部为证据，
底部为来源和页码。数字使用 Consolas；中文为 Microsoft YaHei。
原模板字号以 SVG 像素计，导出器按 96dpi 的 0.75 比例换算为 PowerPoint 点值。

使用页型：封面、指标账页、单主图、条件框架、事件账页、来源清单。
长表在相同表头下分页；长论点拆为独立页；来源行始终在 6.78in 细线下方。
字体可由 Office/LibreOffice 的本机字体替代，不将专有字体打包。
