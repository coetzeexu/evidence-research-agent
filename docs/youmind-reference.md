# YouMind 参考与当前界面规范

2026-09-28，在用户授权并完成登录后查看 [YouMind 新任务页](https://youmind.com/new-task)，通过页面截图与 DOM 计算样式核对。另查看了[公开介绍页](https://youmind.com/zh-CN/overview)。以下参考信息来自当时的观察；当前工作台的实现规则已同步到后续动线、滚动、品牌对齐和事件筛选调整。

## 提取到的设计规则

| 维度     | YouMind 实际页面                                                       | 当前研究工作台的应用                                                         |
| -------- | ---------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 页面结构 | 灰色外层、固定左侧栏、白色圆角内容区                                   | 首页、会话和报告共用白色圆角主区域，顶部导航固定、内容独立滚动               |
| 主次关系 | 中央提问区优先，下方是推荐分类与内容卡片                               | 居中的标题与输入框，下方提供“研究灵感”和“已完成的研究”                       |
| 字体     | 工作台使用系统无衬线字体；中文包含 PingFang SC、Microsoft YaHei 等回退 | 使用系统无衬线字体，不新增字体网络请求                                       |
| 标题     | 32px、400 字重、48px 行高                                              | 宽屏 32px/400；窄屏降至 29px，移动端 27px                                    |
| 主要配色 | 外层 `#f7f7f7`、输入区 `#fff`、主色 `#1f1f1f`、文字 `#000000e0`        | 灰白底色与近黑文字；研究卡片使用低饱和绿、米色区分主题                       |
| 输入区域 | 最大宽度 720px、24px 圆角、1px `#02041a12` 边框                        | 首页输入区域最大 720px、24px 圆角、细边框与轻阴影；主按钮为“开始研究”        |
| 阴影     | 输入区阴影为 `0 1px 4px rgba(2,4,26,.04)`                              | 使用同一量级的轻阴影，取消输入框的双层边框                                   |
| 导航     | 272px 侧栏、浅灰选中背景、无突出边框                                   | 宽屏侧栏 240px，随窗口收窄；品牌与右侧 58px 顶栏对齐，搜索采用灰色圆角聚焦态 |
| 推荐内容 | 胶囊分类、封面、标题与次要说明分层                                     | 两个研究模板使用资产文字封面，点击填入问题；已有报告单独列出                 |

公开介绍页使用 64px 的 Noto Serif SC 衬线大标题。登录后的工作台采用 32px 系统无衬线标题，两者没有混用。

## 交互落地

- 新建研究返回首页并聚焦输入，反复点击保留未发送内容。侧栏不插入未命名草稿，发送成功后才显示实际研究记录；研究灵感只填入可编辑问题。
- 首页去掉模型配置、本地身份、能力口号、点击填入、快捷键与保存提示。研究流程移至顶栏问号，通过独立说明窗口按需查看，支持 Escape 关闭及焦点归还。
- 左侧记录默认打开研究会话，“已完成的研究”卡片直接打开报告；部分完成、待导出等状态按实际记录展示。
- 会话以真实事件生成步骤，不预先展示固定六步；当前活动展开，完成后收起，尊重手动开关。公开笔记、工具状态和来源即时展示，报告就绪后保留同一会话继续追问。
- 移除聊天模式切换和“修改并重跑”入口。资产比较报告的结构化“重算此配置”保留，创建关联原研究的新版本。
- K 线事件语义色独立保留：橙色“高”、蓝色“中”、灰色“低”，问号表示不可评估。封面颜色不代表反应等级；筛选按钮和下拉框保持同步。
- Beautiful UI 的源码适配和 MIT 归属继续保留；YouMind 作为视觉与布局参考，没有引入其业务代码或私有素材。

## 当前布局与控件

| 元素         | 当前规则                                                                                       |
| ------------ | ---------------------------------------------------------------------------------------------- |
| 外层工作区   | `100dvh`；桌面边距 12px，右侧面板 18px 圆角；不随正文滚动                                      |
| 顶栏与品牌   | 共用 `--workspace-header-height: 58px`；左侧 Logo、标题与右侧面包屑/切换区域垂直居中对齐       |
| 主内容       | 首页、会话、报告各自滚动；报告标签在报告内容区内吸顶                                           |
| 会话输入区   | 主会话和报告侧栏均固定在各自底部；运行中的停止操作位于同一区域                                 |
| 自动跟随     | 只滚动消息容器；向上阅读暂停跟随，有新内容时提供返回最新进展入口                               |
| 侧栏搜索     | 默认边框透明，聚焦时为 `#d6d6d6` 浅灰；8px 圆角保持不变                                        |
| 事件反应筛选 | 全部按钮统一 32px 高、8px 圆角；取消深色描边，使用浅底色选中态；色点、文字、数量直接排列并居中 |
| 滚动条       | 全局隐藏，保留滚轮、触控及键盘滚动能力                                                         |
| 侧栏断点     | 默认 240px；宽度 ≤1100px 时 204px，≤850px 时 180px，≤680px 时隐藏侧栏并保留顶栏新建入口        |
| 小屏工作区   | 宽度 ≤680px 时外边距 8px、面板 14px 圆角；会话输入字号 16px                                    |

尺寸、滚动和搜索焦点集中在 [workspace.css](../apps/web/workspace.css)，首页视觉在 [home.css](../apps/web/home.css)，反应筛选在 [research-ui.css](../apps/web/research-ui.css)。修改公共样式时避免首页规则再次覆盖公共焦点或布局。

## 验证范围

- 最近一次事件筛选调整后，前端 24 项测试、Prettier、TypeScript、Web 和离线报告构建通过。
- 使用动线调整阶段已在 811 × 959 CSS 像素的自然视口验证：新建不产生草稿、搜索灰色焦点、帮助窗口、长会话和报告侧栏滚动；外层页面不滚动，顶栏和输入框位置保持不变。原始数据见 [usage-flow-validation.json](../evals/usage-flow-validation.json)。
- 搜索圆角修复后单独验证了聚焦状态为 8px。后续品牌对齐、筛选等高和底色调整通过代码检查与构建，尚未补充浏览器视觉复核。
- 最初 YouMind 首页落地时曾通过 16 项前端测试，并测量 390px、1280px 两个宽度。该历史结果早于固定工作区重构，不能视作当前版本已通过这些尺寸的验收。
- 上述样式调整没有新增模型调用；真实流式研究的独立验收见 [验证记录](validation.md)。
