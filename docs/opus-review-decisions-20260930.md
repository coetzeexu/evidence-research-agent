## 本次落实

- 新增 research_coverage.py。对敏感性成本、权重、频率、分段要求可定位的情景结果；参数标签、重复基线、不同指标拼接不算结果比较。允许多个已接受正文片段共同作答。
- 对 required_event 中明确出现的带数字型号逐一核对，正文与原文引文都要对应；B200/GB200 不能替代 B100。该检查是覆盖的必要条件，仍由原文和语义 reviewer 判断事实及日期是否成立。
- QuestionVerdict 增加 coverage（子项 ID、结论 ID、正文原句）。仅直接绑定问题的 accepted_findings 可以作证；整体 answered=true 不能绕过程序检查。缺失项进入问题缺口和审计，保留已通过内容作为 partial。
- 核验协议升级到 1.5，参与恢复输入哈希。旧版已完成结果不能直接复用为新版认证；历史产物不重写。
- 提示词补充真实 P0 反例及定向补齐规则；修复仍保留已通过结论，不增加调用轮次。
- UI 增加图表加载占位和搜索无结果提示；未启用 design skill，未打开浏览器。
