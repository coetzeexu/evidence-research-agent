# Agent 调研可信度优化方案与验收

本文保留上一轮完整研究验收计划及暂停时记录，不作为新的未完成工程清单。后续用户要求区分模型表现和 loop 缺陷：已修复数值转录与缺口传递，模型观察不列为工程待办；最新结果见 [工程复核](engineering-review.md)。原八次结果保留，不因定向代码修复改写成全通过。

## 目标

Agent 能围绕研究问题自主调查、计算、质疑与补证，最终给出有依据、有边界、具有参考价值的文字结论。沿用 LangChain / LangGraph；本轮仅检查文字与结构化数据，不导出 HTML / Office，不加载图片，不打开浏览器。

| 目标 | 验收条件 |
| --- | --- |
| 回答完整 | 明确要求与必要研究问题逐项有回答、依据、状态，不能用事件数量代替覆盖 |
| 证据可信 | 重要事实定位原文；推断有依据和局限；无无依据的市场预期、机制、因果断言 |
| 数值可靠 | 数字由确定性指标生成；比较区间、频率、币种、费用、执行口径相同 |
| 分析有价值 | 说明观察、竞争性解释、风险代价、适用条件和可改变判断的新证据 |
| 自主有界 | 按问题补查、重算、改写；执行最多 15 分钟；缺证据准确返回 partial |
| 可复核 | 保存问题—证据—指标—结论—核验链、版本和失败记录 |

正常数据条件下两个主场景完整回答必答问题。无法证明因果可以形成有依据的有限结论；用户点名事实缺失必须保留缺口。

## 架构与契约

研究计划 → 数据采集与调查 → 确定性分析 → 结论草稿 → 独立核验 → 定向修复 → 发布正文。

主管维护问题、优先级、完成标准与预算并综合正文；研究子 Agent 按问题获取支持、反证与竞争性解释；核验子 Agent 在独立上下文逐条核对原文、指标和时间。工具承担确定性计算，技能约定方法、边界与停止条件。

在 ResearchBundle.research 中兼容扩展研究问题、证据片段（原文定位、哈希、时间、来源关系）、研究结论（事实/推断/假设、指标、反证、局限）和核验记录。旧 Bundle 为 unassessed，不自动获得正文核验通过状态。

事件分别保存发生、已核实公开、报道、市场反应时间。未知发生时间不排除已知信息公开后的研究；回顾报道日期不能冒充历史公开时间。仅日期精度检查当日/次日窗口。时序吻合是候选关联，不能据此推断市场预期或独立因果贡献。

比较增加同锚点、区间、费用、执行引擎的单资产基线；综合上下文包含敏感性、实际收益和压力期。分别回答避险、抗通胀、配置问题，说明 GLD 代理与 CPI 回顾性分组限制。

首次研究与追问共用结构化正文、引用/数值检查、独立语义核验、定向修复门禁。数字用指标引用格式化；严重发现不得按 Claim ID 自动降级。未经核验的草稿不得流入正文或聊天历史。

## 预算与接口

- 完整调研最多 900 秒实际执行时间（排队不计）；恢复沿用预算。720 秒后停止调查，剩余时间用于综合/核验。
- 最多两轮检索补查、两轮正文修复；全程最多 34 次搜索、50 次读取、64 次模型调用。
- 到期仅发布已核验内容与缺口；没有可发布内容则失败。
- SSE 输出真实操作、问题、来源进展；核验通过后一次发布正文，兼容 accepted/delta/done/error。
- 追问基于当前快照，180 秒总预算；新增数据/范围应重新研究。
- GET /api/runs/{id}/research 与 CLI 文字查看入口；持久化 export_reports，默认兼容现状，本轮显式关闭。
- 研究完成度独立于文件生成状态。

## 已确认基线问题

旧 explain() 直接调用模型并流式发布，没有检查最终文字。实际冻结样例问答出现：Blackwell「市场已有预期」无证据解释、组合与单资产区间不同仍直接比较、CPI 相关性推导「抗通胀属性不成立」、计算结论错引新闻来源、已有敏感性未进入解释上下文。旧样例证据核验通过不能证明这些文字正确。

原始文字及复核证据来自工作区 work/agent-text-review-20260929；后续评估保存结果并区分基线、失败尝试与最终验收，不覆盖历史。

## 固定版本候选 A 与故障验收

2026-09-29 已启动 `candidateAEvents`（NVDA 连续三次 + AMD）和 `candidateAComparison`（GLD/BTC 连续三次 + GLD/ETH），两个序列使用同一生产代码/Prompt/技能哈希；运行期间冻结生产文件。候选批次只有全部自动条件及独立内容审阅通过，才转为最终通过记录。每次结果包含原始 Bundle、正文、研究记录、版本、实际返回模型和用量；不得删除失败运行。

真实模型故障检查 `faults-42a4fe735a53462f.json` 已通过：构造来源含错报日期、相互冲突与提示注入，固定真实指标构造 CPI 过度推断及错误收益排名；仅正确对照结论获准发布。该检查验证生产核验器面对预期失败的行为，不替代八次正常场景及独立原文审阅。

当前工程验证：121 项纯文字后端回归通过，3 项真实报告导出测试按本轮约束跳过；前端 28 项、TypeScript、Prettier 和 Ruff 通过。没有运行浏览器或生成报告文件。

候选 A 首个 NVDA 运行 `8118319287e54600` 在事件核验提取中触发 GraphRecursionError，尚未生成可发布正文。其余在途尝试主动中止并保留 `interrupted-*.json`；本批不能计为完成八次验收。根因是无工具的结果提取阶段继承了带旧工具调用的对话，模型继续索取旧工具。改为独立工具空上下文，将已取得的原文与核验笔记作为数据输入，使用专门 review-format Prompt；重放同一证据后能返回实质缺陷，未将真实缺陷清零。正式固定版本八次验收仍待完成。

第二次故障检查 `faults-f380841f11404780.json` 修正 CPI 指标 ID 后仍仅接纳正确对照，CPI 过度断言在有效数值引用下被拒绝。保留首轮含缺失指标的故障记录，不把引用错误掩盖的拒绝当作唯一语义证据。

定向复验 `smokeGold6` 发现整段改写会保留“2025-03 BTC 为正”的错误句并追加“为负”，仍被程序拦截；`liveNvda4` 发现定性“关联可信度最高”被数值关系检查误拦截。修复改为精确文本补丁协议，已核验条目不可修改，补丁执行后重新审查整条结论；定性置信评级留给证据语义核验，不与财务排序混用。日期证据加严，泛化“我们发布模型”或 URL 路径不能独自证明具体日期。128 项后端回归通过；新一轮主场景仍在执行。
